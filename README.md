# Bourbon Street Brawl (play page)

Play in the browser: https://cr3ole.github.io/bourbon-street-brawl-play/

This repo only holds the built game (`index.html`, plus `og.html`, the original V1). Made by ya baw Creole.

Online co-op: the host opens the link on a computer in Chrome and picks **Play Online with a Friend → Host a game**.
The friend opens the same link (a computer or a phone), picks **Join a game** and types the 5-letter code. On a phone, turn it sideways.
